# 汽车出口价小程序 UI

本次交付包括三个 393 × 852 画板：新对话、车型报价、历史对话抽屉。SVG 保留文字和矢量图层，可导入 Figma。因当前会话没有可调用的 Figma MCP 工具，且浏览器连接报错 `unsupported Codex auth method: apikey`，尚未写入 Figma 云端。SVG 导入不会自动建立 Auto Layout、共享组件或原生原型连线。

## 视觉与结构

- 白底，文字 #182924，次级文字 #60716A，主色 #147D5E，选中背景 #EAF5EF，边线 #E7ECE9。
- 首页功能入口以绿色、蓝色、青色、琥珀色区分；Lucide 线性图标，避免混用 emoji。
- 基准字号 14px，主标题 24px，报价 19px，辅助文案 10–12px。中文系统字体 Microsoft YaHei / PingFang SC。
- 左右边距 20px，卡片圆角 8px，控件圆角 6px。保留微信胶囊和底部首页、车价计算器、我的。
- 报价统一按配置、颜色、指导价、美元单价排列，共用 FOB 南沙信息；灰色、白色筛选，展开完整配置，报价来源与复制反馈。
- 历史抽屉宽 312px，从顶部导航栏以下展开，保留微信胶囊；其余 81px 显示底层对话与遮罩。点击遮罩、收起按钮或 Escape 关闭。
- 历史列表含置顶、今天、昨天、近 7 天分组。搜索支持标题与摘要，包含无结果状态；新建对话回到首页，点击历史条目进入相应会话。

## 价格与数据边界

截图可完整确认的 8 个报价被逐项保留，币种 USD，贸易形式 FOB，交付地南沙。截图底部截断的白色 968+包价格未纳入，未推测缺失数字。历史对话标题及日期是 UI 示例。预览中的输入与计算器使用本地状态，未连接 AI、报价表、用户账户或真实历史记录。报价来源入口明确标识截图示例。

## 开发映射

实现时建议提取小程序组件：NavigationBar、QuickEntry、MessageComposer、QuoteRow、QuoteFilters、BottomTabBar、HistoryDrawer、HistoryItem。抽屉打开时禁止背景滚动，并将焦点限制在抽屉内。实际对话应以唯一 conversation_id 持久化；分组使用用户当地时间。车型和配置匹配以源报价表为准，不能把缤越与缤越 L 合并。真实报价查询应补齐加载、失败重试、无匹配、来源不可访问和过期提示状态。

## 验证记录

本地使用 Playwright 驱动独立无头 Chrome 渲染；没有访问已有浏览器会话。393 × 852（2 倍像素）、360 × 800、1440 × 1080 三种预览尺寸通过检查。三屏文本边界及页面水平溢出检查通过，浏览器脚本错误为 0。历史搜索、无结果、选择对话、新建对话、颜色筛选、完整配置、计算器和消息输入均已验证。

已对照 SVG 总览与浏览器截图检查文字、价格、留白、配色、图标、导航及抽屉位置。修复了历史分组标题贴近上一条对话的问题、窄屏预览横向溢出问题，以及抽屉遮挡微信胶囊的问题。预览图与 SVG 采用同一套布局数据。此次是基于原截图重新设计，没有先前经用户确认的新版概念图；绿色视觉与报价列表布局是本轮设计选择，尚待用户审阅。
