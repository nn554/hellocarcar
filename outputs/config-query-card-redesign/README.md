# Hellocarcar 配置表查询卡片化重设计

## 交付文件

- `hellocarcar-config-query-desktop.svg`：桌面端完整页面，1440 × 1024。
- `hellocarcar-config-query-mobile.svg`：移动端滚动页，390 × 1200。

两张 SVG 均为自包含文件，车型图片已内嵌，可直接拖入 Figma。

## 修改范围

- 保留原有深绿侧边栏、顶栏、导航顺序和基础配色。
- 原“制作”入口改为“查询配置”。
- 新增“热门车型配置”卡片区，所有价格统一为美元报价。
- 专门配置表功能模块改为一张完整流程卡片，并在车型卡片中展示美元价格。
- 桌面端采用横向车型卡片与三列配置卡片；移动端采用单列配置卡片和底部固定操作区。

## 报价样例

报价沿用工作区此前从用户指定飞书报价表提取的记录：

- 海狮06 DM-i · 121KM 领航版：`$19,084`
- 海豹06 DM-i · 80KM 尊贵型：`$12,309`
- 秦L DM-i · 120KM 旗舰型：`$17,459`
- 唐DM-i 智驾版 · 115KM 尊贵型（7座）：`$20,909`

页面保留“仅供配置查询参考”的提示，避免把记录报价误解为实时成交价。

## Figma 导入建议

1. 将两张 SVG 直接拖入现有 `hellocarcar` 页面。
2. 桌面版建议放在现有配置表画板附近，命名为 `配置表-查询配置-Desktop`。
3. 手机版建议命名为 `配置表-查询配置-Mobile`。
4. 如需继续编辑文字与图层，导入后取消编组即可。
