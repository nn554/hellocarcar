# Hellocarcar 车辆报价界面重设计

## 交付文件

- `hellocarcar-vehicle-quote-desktop.svg`：桌面端完整页面，1440 × 1280。
- `hellocarcar-vehicle-quote-mobile.svg`：移动端滚动页，390 × 1760。

两个 SVG 均为自包含文件，车标和车型缩略图已内嵌为 PNG data URI，可直接拖入 Figma。

## 交互说明

1. 页面初始展示价位筛选和品牌入口，不直接展示全量报价。
2. `全部价位` 为默认态；选择 `< $10,000`、`$10,000–$20,000` 或 `> $20,000` 后，仅保留至少有一条对应价位配置的品牌。
3. 点击品牌后，在品牌区下方展开该品牌的配置报价列表，同时保留品牌区，方便快速切换品牌。
4. 报价列表把“车辆”和“配置”合并为一列：上方展示车型缩略图，下方展示“车型 · 配置”。
5. 原“有效期”列移除，替换为“查看车型配置表”按钮。
6. 移动端将同一信息重排为纵向报价卡片，避免横向表格滚动。

## 数据与素材

- 品牌范围来自用户提供的飞书报价表 4 个品牌分组页，共 33 个品牌入口。
- 示例报价来自飞书表格的比亚迪报价数据。
- 车标来自 `品牌车标.zip`。
- 车型缩略图来自 `车型缩略图_HelloCarCar_完成版.zip`。
- 素材包未提供雪铁龙、星途、腾势的独立车标，原型中使用标准文字标识；东风纳米使用东风集团标识。
